Copy protection is installed in the React root layout and standalone entry for all pages. Document capture listeners block copy, cut, contextmenu and dragstart, including form fields and dialogs. CSS disables page text selection and WebKit touch callouts; a selectstart listener also blocks selection outside editors. Form text remains selectable for editing, but copy and cut are blocked. Typing, pasting, scrolling and zoom remain available. This deters ordinary copying; screenshots, source access and disabled JavaScript can bypass it.

After building, deploy all four generated HTML pages through the existing GitHub Pages workflow. Local edits do not update arc-ai.in until deployed. Verify right-click and Ctrl/Cmd+C on desktop, long-press on text, images and links in iOS Safari and Android Chrome, and typing/pasting into the sample checker. Browser-owned menus can differ by device; a narrow desktop viewport is not a real-device long-press test.
